# Student Performance Risk Predictor

A simple, interpretable machine learning system that predicts whether a student is at academic risk using attendance and performance trends.

## Features
- Logistic regression model for transparency
- Uses attendance, assignment scores, exam scores, and late submissions
- Designed for early intervention, not automated decisions

## Tech Stack
- Python
- pandas
- scikit-learn

## Use Case
This model is designed to support educators by flagging students who may benefit from early academic support.

## Ethical Design
Predictions are intended as decision support and should always be reviewed by instructors.
